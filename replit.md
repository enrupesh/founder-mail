# Founder Mail

## Project overview

Founder Mail is a React/Vite email dashboard backed by an Express server. It listens on port 5000, stores messages in `data/messages.json`, and integrates with Resend for receiving and sending email.

## User preferences

- Keep the existing React, Vite, Express, and Node 20 structure.
- Prefer small, focused deployment fixes over migrations or broad refactors.
- Keep deployment instructions explicit about required environment variables and external service setup.
